## About the Repository

Welcome to my Full Stack Development Lab repository! This repository contains the practical assignments and projects completed as part of my TYBCA coursework.

The work focuses on building web applications, understanding frontend and backend technologies, managing databases, and integrating different tools to create functional applications.

## Technologies & Tools

- **Frontend:** HTML, CSS, JavaScript, React.js
- **Backend:** Node.js, Express.js
- **Database:** MySQL, Sequelize ORM
- **State Management:** Redux Toolkit
- **Module Bundling:** Webpack
- **Development Tools:** Visual Studio Code, npm, Git, GitHub

## Topics Covered

- JavaScript fundamentals and asynchronous programming
- Node.js file handling, streams, and piping
- Express.js routing and API development
- Scheduled tasks and file operations
- MySQL database connectivity and Sequelize ORM
- Database relationships and associations
- React components, state management, and UI development
- Redux and application state management
- Webpack configuration and module bundling
- Integration of React frontend with Node.js backend

## Learning Objectives

Through these practicals, I aim to develop hands-on skills in:

## How to Run

1. Install [Node.js](https://nodejs.org/).
2. Clone or download this repository.
3. Open the required practical folder in Visual Studio Code.
4. Install the required dependencies, if applicable:

   ```bash
   npm install
   ```

5. Run the program using the command specified for that practical. For example:

   ```bash
   node app.js
   ```

   For React projects using Vite:

   ```bash
   npm run dev
   ```

*Some practicals require additional setup, such as a running MySQL server and valid database configuration.*
